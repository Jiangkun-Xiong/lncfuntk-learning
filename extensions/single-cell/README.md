# 条件分支 / 单细胞

当前状态：保留规划，尚未开展。

当问题需要区分细胞类型、状态比例或细胞内表达变化，而整体平均值不足以回答时，再进入本分支。

## 前置条件

- 能读懂表达矩阵、样本信息与生物学重复。
- 能区分细胞数与独立样本数。
- 能说明基础质控或分组怎样影响解释。

## 可选学习与产出

先用公开教程理解数据对象、质控、降维、聚类与注释，再决定如何迁移到肌肉干细胞问题。PBMC 教程结果应称为教程练习，不应称为完成了肌肉干细胞分析。

产出应包含：问题说明、样本与细胞信息、带选择理由的笔记及一种替代解释。暂不预设必须使用某个工具，也不把单细胞作为 FIS 模块的前置。
