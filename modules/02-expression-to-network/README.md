# 02 / 表达与网络证据：评分输入从哪里来

前置：[01 算懂 FIS](../01-fis-scoring/README.md)。当前状态：任务规划，未执行真实数据分析。

FIS 的输入是网络邻居计数。学习表达分析，是为了理解网络证据的来源。

## 最小任务

- [ ] 选定来源清楚、规模可控的教学矩阵，先确认行、列、表达单位和独立重复。
- [ ] 填写 [sample-sheet.example.tsv](sample-sheet.example.tsv)。当前仅有表头，不代表已有数据。
- [ ] 记录基因标识、物种、基因组版本、条件与批次。
- [ ] 区分差异表达与共表达：前者比较条件间变化，后者考察跨样本关系。
- [ ] 解释一个小型共表达边表的规则与局限。
- [ ] 对照原工具输入说明，指出 RNA-seq、ChIP-seq、AGO2 CLIP-seq 各提供什么证据，教学练习还缺什么。

## 完成门槛

一份填实的样本表、一份矩阵说明、一份可追溯的边表和一段“边不等于因果”的解释。实际完成后再加入脚本和结果。

先填写 [analysis-plan.md](analysis-plan.md)，再开始实现。显著差异表达基因列表不能直接等同于调控网络。
