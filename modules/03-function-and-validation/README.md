# 03 / 从分数到可检验的功能假设

前置：[02 表达与网络证据](../02-expression-to-network/README.md)。当前状态：后续任务规划。

理解网络边和背景集合的来源后，才能审查“排名较高”支持什么解释。优先级、筛选阈值、GO 富集与实验因果是不同层次。

## 最小任务

- [ ] 解释 FIS、p 值和多重检验校正指标的区别。
- [ ] 阅读上游随机网络和功能注释步骤，记录与当前练习的缺口。
- [ ] 定义富集分析的背景集合，记录基因标识匹配。
- [ ] 将候选、关联证据、假设与不能成立的结论分开。
- [ ] 填写 [hypothesis-card.md](hypothesis-card.md)，说明替代解释、对照与验证思路。

完成门槛：解释一个有来源的功能注释示例，并说明实验验证还需要增加什么。六个合成候选不对应真实生物学对象，不能赋予真实 GO 功能或显著性。
